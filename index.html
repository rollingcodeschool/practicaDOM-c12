Practica DOM

Introducción al DOM con JavaScript

El DOM es una representación del HTML como objetos en JavaScript. Nos permite modificar elementos en la página mientras se ejecuta.

🔍 Selección de elementos

Métodos del objeto document

  • getElementById('id') → Selecciona por ID.
  • getElementsByClassName('clase') → Selecciona por clase.
  • getElementsByTagName('tag') → Devuelve por tipo de etiqueta.
  • Devuelve por tipo de etiqueta. → Devuelve el primer elemento que coincide.
  • querySelectorAll('selector') → Devuelve todos los que coinciden.

✏️ Modificar contenido:

  • textContent agrega texto plano (más seguro).
  • innerHTML interpreta HTML (⚠️ vulnerable a XSS si no secontrola).

🎨 Manipular clases con classList:

classList es una propiedad de los elementos DOM que permite trabajar fácilmente con las clases CSS. Devuelve un objeto con métodos útiles.
